# 2026-11-15 Check Price: no screen titles, icon-only tab bar

- Author: Claude agent (Opus), for Andrew. Branch `checkprice-ios`.
- Instruction (owner): "for the app there should be no titles, and for the bar there should only be the icons and no names under it either, and use better icons if available."
- Removed titles: Home's "Check Price" heading (`PrimaryCheckArea`), the "Threads" heading (`ThreadsView`; the filter chips are now the first row), the "Settings" bar title (`AccountSettingsView`; the bar keeps only the back button), and the "Edit profile" sheet title (`EditProfileSheet`; Cancel and Done stay). The thread detail had no title. Section labels that name content (Summary, Verdicts, Recent, Price, Chat, Set up) stay.
- Kept: the Account top bar's handle, since it is profile info as on Instagram. Its fallback word "Account" (shown when no handle is set) is gone; the corner is empty until a handle is set.
- Tab bar: icons only. Symbols: Home `house` / `house.fill`, Threads `bubble.left.and.text.bubble.right` / `.fill`, Account `person.crop.circle` / `.fill`, outline when not selected and filled when selected. Each name was checked in macOS's SF Symbols availability list (`CoreGlyphs.bundle/.../name_availability.plist`): the bubble pair is iOS 17, the others iOS 13. `.environment(\.symbolVariants, .none)` stops the system from filling the unselected icon.
- How the labels are hidden: each tab still has its title, so VoiceOver reads Home, Threads, Account; `TabBarStyle` draws titles in clear. UIKit still keeps space for the title, so `TabBarIconInsets` (in `Components/TabBar.swift`) sets each item's `imageInsets` to 6 pt down to centre the icons. The bar's height is the system's and was not changed; icons are the system size.
- Checks: `xcodegen generate`; `scripts/typecheck.sh` passes (app and widget). Also type-checked in Swift 6 mode: no new warnings (one existing warning in `ThreadsListRow.swift`).
- Not verified: nothing has been seen on screen (no full Xcode or simulator on this machine). The 6 pt icon offset is the usual value for a titleless tab bar and may need tuning; whether the inset hook survives SwiftUI's item updates is untested.
